# UI / shared components

This folder contains shared UI built with [shadcn/ui](https://ui.shadcn.com/). Use these components for new UI (buttons, forms, cards, etc.) across the app.

- **Button** – shadcn Button (default, outline, ghost, link, destructive). Use `<Button asChild><Link href="...">...</Link></Button>` for link-styled buttons.
- **RedirectButton** – CTA that redirects to whitelist; uses Button.
- **RevealOnScroll** – scroll-triggered reveal wrapper.
