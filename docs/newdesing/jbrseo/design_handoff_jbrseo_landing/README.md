# Handoff: JBRSEO — صفحة الهبوط (Landing) — اتجاه "نتيجة البحث الحيّة"

## نظرة عامة (Overview)
صفحة هبوط لخدمة **JBRSEO / مدونتي** — سيو بالاشتراك الشهري يستهدف السوق السعودي والمصري.
الفكرة المحورية: بدل ما نقول "نخليك في المركز الأول على جوجل"، الصفحة فيها **لوحة بحث حيّة** يصعد فيها موقع العميل من المركز السادس إلى **#1** تلقائيًا أمام الزائر — المنتج يعرض نفسه.
الطابع العام: **بساطة، مساحات بيضاء، أكسنت أخضر واحد، أزرار سوداء**.

> **اللغة واتجاه الصفحة:** كل المحتوى عربي و **RTL** (`dir="rtl"`).

---

## عن ملفات التصميم (About the Design Files)
الملف المرفق `JBRSEO v2.dc.html` هو **مرجع تصميم مكتوب بـ HTML** — نموذج (prototype) يوضّح الشكل والسلوك المقصودين، **وليس كودًا للإنتاج يُنسخ مباشرة**.
المطلوب: **إعادة بناء هذا التصميم داخل بيئة المشروع الحقيقية** (Next.js / React مثلًا — الموقع الأصلي مبني على Next.js) باستخدام أنماط ومكتبات المشروع المعتمدة. لو ما فيه بيئة بعد، اختر الإطار الأنسب (نقترح **Next.js + React + TypeScript** لأن الموقع الأصلي عليها) ونفّذ التصميم فيها.

المنطق التفاعلي في النموذج مكتوب بـ React (داخل صيغة "Design Component")؛ تقدر تترجمه مباشرة لمكوّنات React عادية — منطق الحالة (state) موصوف بالكامل تحت.

## درجة الدقة (Fidelity)

الصفحة **واحدة طويلة** (single page) بعرض محتوى أقصى `max-width: 1080px` (الهيرو واللوحة أضيق). المقاطع بالترتيب:

- **يمين (البداية في RTL):** الشعار = مربع أسود `30×30`, `border-radius:8px`, خلفية `#0A0A0A`, الحرف `J` أبيض 700/14px + النص `jbr` أسود و `seo` أخضر `#0E9F6E`، الوزن 600، الحجم 17px، `letter-spacing:-.3px`.
- **يسار:** مبدّل السوق (نصّي): زرّان `السعودية` / `مصر`، 13px، الزر النشط خلفية `#0A0A0A` نص أبيض `border-radius:8px padding:6px 12px`، غير النشط نص `#9A9A93`. ثم زر CTA أسود "ابدأ الحين" (`padding:10px 18px; radius:10px; 14px/500`).

- **Eyebrow:** "سيو بالاشتراك الشهري · السعودية ومصر" — 14px/500, لون `#6B6B66`, مسافة سفلية 26px.

### 3) لوحة البحث الحيّة (Live SERP) — *قلب الصفحة*
- حاوية `max-width:640px`. بطاقة بيضاء: `border:1px solid #E8E8E2; border-radius:20px; box-shadow:0 30px 60px -36px rgba(10,10,10,.28); overflow:hidden`.
- **شريط البحث (أعلى البطاقة):** صف flex، padding `18px 22px`, حد سفلي `#F0F0EA`. يحتوي: أيقونة عدسة (SVG دائرة + خط، stroke `#9A9A93`) + نص الاستعلام (15px لون `#2A2A26`) + مؤشر كتابة وامض (caret) + كلمة "بحث جوجل" مونو 11px لون `#B8B8B0`.
- **قائمة النتائج:** حاوية `position:relative` بارتفاع ثابت = `(عدد الصفوف=6) × 62px + 12 = 384px`, خلفية `#FCFCFA`, padding `10px 14px`.
- **كل صف نتيجة** عنصر `position:absolute; left:14px; right:14px`, ارتفاع `54px` (`ROWH-8`), `top = index × 62 + 6`, مع انتقال (transition):
  `top .55s cubic-bezier(.34,1.2,.34,1), box-shadow .4s, border-color .4s, transform .4s`.
  - **صفوف المنافسين:** خلفية شفافة، حد شفاف، عنوان رمادي (`#86867E`/`#52524C`)، رابط مونو 11.5px رمادي.
  - **صف العميل ("نشاطك التجاري"):** خلفية بيضاء، `border:1.5px solid #0E9F6E`, `box-shadow:0 10px 26px -12px rgba(14,159,110,.45)`, عنوان أسود 600، شارة خضراء "موقعك" (`#0E9F6E` على `#E6F7EF`)، رابط أخضر `your-business.com`.
  - **شارة الترتيب (يسار الصف):** مربع `30×30 radius:8px` مونو 13px/600. للمنافس خلفية `#F0F0EA` نص `#9A9A93`. للعميل `#E6F7EF`/`#0E9F6E`، وعند الوصول للمركز #1 تصبح خلفية `#0E9F6E` ونص أبيض.
  - **شارة "إعلان"** على المنافس الأول (`competitor-ads.com`) ما دام أعلى من العميل: 10px/600 لون `#B26B00` خلفية `#FFF3DC` مونو. تختفي عندما يتجاوزه العميل.
  - أثناء الصعود: مؤشر "▲ يصعد" أخضر يتحرك (`animation:up`). عند الوصول: "المركز الأول ✓" أخضر مع `animation:pop`.
- **تعليق أسفل اللوحة:** "من الصفحة الخامسة إلى المركز الأول — هذا اللي نسوّيه لموقعك." 13px لون `#9A9A93`.

### 4) كيف نعمل (How) — سطر واحد هادئ
- شبكة 3 أعمدة، `text-align:center`، فواصل رأسية `border-right:1px solid #EDEDE8` بين الخلايا.
- كل خطوة: رقم عربي مونو (`٠١/٠٢/٠٣`) لون `#B8B8B0` + عنوان 20px/600 + وصف 14px لون `#7A7A73`.
  1. **اشترك** — "اختر باقتك وتعبّأ استمارة قصيرة مرة وحدة."
  2. **نكتب وننشر** — "فريقنا يجهّز المحتوى وينشره على موقعك تلقائياً."
  3. **تتصدّر جوجل** — "تظهر في البحث، والعملاء يجونك كل يوم."

### 5) "الرياضيات بسيطة" (Math) — مقارنة تكلفة
- قسم بخلفية بيضاء `#fff` بحدود علوية/سفلية `#EDEDE8`, padding `72px 28px`, مُتمركز.
- عنوان "الرياضيات بسيطة." 38px/600 + سطر "عشان تتصدّر جوجل تحتاج فريق ٦ وظائف. أو اشتراك واحد." (16px `#7A7A73`).
- مقارنة أفقية: **فريق داخلي كامل** = `37,000` مونو 46px لون `#C4C4BC` مشطوب (line-through بلون `#E2A0A0`) → سهم `←` → **مدونتي اشتراك واحد** = `100` مونو 60px/600 أسود، تحته "ر.س / شهرياً — يبدأ من".
- شارة خضراء (pill): "توفير يصل إلى ٩٧٪ — ومحتوى يبقى ملكك للأبد" على `#E6F7EF` لون `#0A7A52`.

### 6) الباقات (Pricing)
- عنوان "باقات تنمو معك" 38px/600 + سطر "أسعار التأسيس — أول ١٥٠ شركة. ضمان استرجاع ١٤ يوم."
- **مبدّل الفوترة:** segmented على خلفية `#F0F0EA radius:11px`: "شهري" / "سنوي · ٦ أشهر هدية". الزر النشط أبيض بظل خفيف.
- شبكة **4 بطاقات** `gap:14px`. كل بطاقة `radius:18px; padding:26px 22px`. الباقة المميزة ("الزخم") **خلفية سوداء `#0A0A0A`** نص أبيض و`box-shadow:0 24px 50px -22px rgba(10,10,10,.5)`؛ البقية بيضاء بحد `#E8E8E2`.
- كل بطاقة: اسم (14px/600) + سطر تعريف + السعر (مونو 36px/600) + "ر.س/شهر" + ملاحظة مونو ("سنوياً X ر.س" في الوضع السنوي) + زر CTA + فاصل + 3 مزايا بعلامة ✓ خضراء.

| الحضور | 100 | 100 | مقال احترافي يعكس خبرتك · صفحة تعريفية جاهزة · رابط خاص تشاركه |

### 8) الفوتر (Footer)

### 9) أيقونة الحاسبة العائمة + النافذة (Floating Calculator FAB + Modal)
- **FAB:** زر `position:fixed; bottom:24px; left:24px; z-index:60`، أسود `#0A0A0A`، نص أبيض، `border-radius:99px; padding:14px 18px`, `box-shadow:0 16px 36px -10px rgba(10,10,10,.5)`، يحوي أيقونة آلة حاسبة (SVG) + نص "احسب توفيرك". يظهر بـ `animation:fabIn`.

  - تذييل النتيجة: بطاقة `#FAFAF7`: فريق كامل/سنوياً (مشطوب) + مدونتي/سنوياً `12,468` + لوحة سوداء فيها **نسبة التوفير** (مونو 40px لون `#3DDC8C`) ومبلغ التوفير السنوي. ثم زر "شوف الباقة المناسبة لك ←" (يُغلق النافذة وينتقل لـ #pricing).

  **أدوار الحاسبة (القيمة الافتراضية / الحد الأدنى / الأعلى، الخطوة 100، بـ ر.س):**
  | الدور | افتراضي | min | max |
  |---|---|---|---|
  | كاتب محتوى SEO | 4500 | 2500 | 12000 |

## التفاعلات والسلوك (Interactions & Behavior)
- **صعود الـ SERP (تلقائي، حلقي):** تبدأ القائمة بترتيب `['ad','c2','c3','c4','c5','you']` (العميل آخر = #6). كل **760ms** يتبادل صف العميل مع الصف الذي فوقه (يصعد درجة). الصفوف مموضعة absolute بحسب فهرسها فتنزلق بسلاسة. عند وصول العميل للقمة، توقّف **2800ms**، ثم بدّل نص الاستعلام للتالي وأعد الترتيب الابتدائي وكرّر. الاستعلامات: `['شركة مقاولات بالرياض','عيادة أسنان بجدة','متجر قهوة مختصة','مكتب محاماة بالقاهرة']`. (نظّف المؤقتات عند unmount.)
- **مبدّل السوق (sa/eg):** يبدّل العملة (`ر.س` ↔ `ج.م` — طبّقها أينما ظهرت)، ورقم واتساب (`966541018020` ↔ `201000000000`). *(ملاحظة: رقم مصر placeholder — استبدله بالرقم الحقيقي.)*
- **مبدّل الفوترة (monthly/annual):** يبدّل الأسعار المعروضة وملاحظة "سنوياً X".
- **FAB → Modal:** فتح/إغلاق بحالة `calcOpen`. الإغلاق بالنقر على الخلفية أو زر ✕ أو زر CTA داخل النافذة.
- **المنزلقات:** `onInput` يحدّث `salaries[key]`، فتُحدّث التعبئة والنتيجة فورًا.

### الأنيميشن (keyframes)
- `caret` (وميض المؤشر، 1s step-end) · `up` (تمايل "يصعد") · `pop` (ظهور "المركز الأول") · `fabIn` · `sheetIn` (cubic-bezier(.34,1.1,.4,1)) · `fadeIn`.

## إدارة الحالة (State Management)
```
market:    'sa' | 'eg'                    // مبدّل السوق
billing:   'monthly' | 'annual'           // مبدّل الفوترة
queryIdx:  number                         // فهرس الاستعلام الحالي في SERP
order:     string[]                        // ترتيب صفوف SERP (ids)، يتحرّك بالمؤقت
calcOpen:  boolean                        // فتح/إغلاق نافذة الحاسبة
salaries:  { writer, designer, seo, social, video, dev }  // قيم المنزلقات
```
لا يوجد جلب بيانات (no data fetching) — كل المحتوى ثابت ما عدا روابط واتساب والـ CTA (وجّهها لمسارات التسجيل الحقيقية مثل `/sa/signup`).
