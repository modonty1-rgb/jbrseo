## 🚀 المقترحات الاستراتيجية الخمسة (تغيير جذري)

### 1. استبدال IBAN بدفع فوري
mada + Apple Pay + STCPay + Tamara — inline في `/signup` (single-page checkout). **يرفع التحويل من ٢٠٪ إلى ٧٠٪.**
✅ **يُنفَّذ الآن عبر N-Genius.**

### 2. لهجة سعودية موحّدة + إزالة "beta"
كل نصوص `/sa` بلهجة سعودية، إزالة «تجارب مبكرة»، استبدال بـ «ضمان ٣٠ يوم» بارز في hero وبجانب كل CTA.

### 3. Single-page conversion
Hero → Live SERP → أسعار (٣ باقات) → Form → Payment — نفس الـ URL بـ smooth scroll، بدون قفزة إلى `/signup`.

### 4. هيدر واحد + CTA واحد
حذف `LandingHeader` + `AuthNav` + `SiteLayoutFallback`، الاحتفاظ فقط بـ `Navbar`. CTA موحّد: «جرّب مجاناً ٣٠ يوم — بدون بطاقة».

### 5. Trust Row ثابت أسفل Hero
عدد العملاء + شعار السجل التجاري + ZATCA + WhatsApp + تقييم Google + سطر «عملاء في: الرياض، جدة، الدمام، الطائف».
